# LED Blinking using Verilog and SmartFusion SoC

## Overview

This project documents my learning and implementation of a basic LED-blinking design using Verilog HDL and the SmartFusion A2F500 development kit during my internship at Hindustan Aeronautics Limited (HAL), Bengaluru.

## Tools and Platform

- Verilog HDL
- Microchip Libero SoC v11.8
- SmartFusion A2F500 development kit

## Design Concept

The design uses a clock-driven counter to generate a slower LED-toggle signal from the input clock.

## Design Flow Studied

1. Verilog RTL development
2. Clock and I/O configuration
3. RTL synthesis
4. Place and route
5. Device programming
6. Hardware output validation

## Learning Outcomes

- Synchronous digital logic and counters
- Clock division and timing concepts
- FPGA synthesis and implementation flow
- I/O pin mapping
- Hardware debugging and validation

## Project Status

This repository documents the project and the concepts learned. The original HAL project files are not included because I did not retain them.
